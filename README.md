# Guan21.github.io

Guan21 的个人主页第一版，面向 GitHub Pages。

## 文件结构

- `index.html`: 页面内容和结构
- `styles.css`: 视觉样式和响应式布局
- `script.js`: 年份和占位链接处理
- `assets/hero.png`: 首页视觉图
- `assets/favicon.svg`: 站点图标

## 下一轮建议补充

1. 把 `Guan21` 替换成你希望公开使用的姓名或昵称。
2. 用 3 个真实项目替换“项目 A/B/C”。
3. 添加公开联系方式，例如邮箱、微信说明、LinkedIn 或作品集链接。
4. 把“想法入口”里的三篇文章写出来，主页会立刻更像一个长期资产。

## 内容结构

当前页面新增了三块可继续扩展的内容：

- `第一篇：为什么我要做个人主页`
- `内容地图`
- `项目复盘模板`

这些内容不依赖私人信息，可以先公开；后续再用真实作品替换模板位。
