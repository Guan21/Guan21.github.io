Flagship Case: Local AI Agent Control Plane

DevCrew / cc-orca is the strongest public case because it has verifiable implementation history, merged PRs, reviewable architecture concepts, and concrete safety work.

Public Evidence Case

DevCrew: local agent activity, review, and corporate network governance

Repository
Problem
AI coding agents create useful work, but teams need visibility into activity, project context, change impact, review queues, disagreement signals, and corporate network policy before the workflow can be trusted.
Ownership
Designed and implemented public DevCrew capabilities around project intelligence, activity visualization, impact review, endpoint scanning, egress remediation, and runtime contract tests.
Architecture Decisions
Model agent work as observable development events, turn them into project maps and activity graphs, and add safety gates that make corporate network assumptions explicit instead of implicit.
Implementation
Implemented Activity Graph v1, observed Project Map details, Change Impact composition, forbidden endpoint scanning, corporate egress remediation, and runtime egress release gates.
Validation & Outcome
Six related PRs are merged. The corporate forbidden endpoint scanner remediation path reduced static findings from 71 to 0. This is a bounded static and runtime-contract claim, not a claim that every possible network risk is eliminated.
